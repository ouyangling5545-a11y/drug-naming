# 创新药命名管理系统 — 用户手册

## 系统概述

本系统为创新药 INN（国际非专利名称）申请、中文核名、商品名筛选提供一站式管理平台。核心能力包括：

- **词干匹配**：输入分子药理性质，自动匹配 WHO INN 词干（514 条词干库）
- **名称生成**：基于词干组合规则生成 INN 候选名，自动去重 9,378 条已有 INN 名称
- **POCA 评分**：FDA 标准的语音/字形/组合三维度相似度评分，智能选择同类药对比
- **中文核名**：拼音映射 + 字形分析 + 合规检查
- **商品名筛选**：多维度评估（INN相似度、品牌相似度、语义、市场可注册性）

---

| `integrin` | 整合素 |

## 二、API 端点详解

### 2.1 词干匹配

**`POST /api/v1/stems/match`**

输入分子药理性质，返回匹配的 WHO INN 词干列表（按匹配得分降序）。

请求示例：
```json
{
  "target_class": "kinase",
  "mechanism": "inhibitor",
  "chemical_class": "small_molecule",
  "indication": "non-small cell lung cancer"
}
```

响应示例：
```json
[
  {
    "stem": {
      "stem": "-tinib",
      "position": "suffix",
      "category": "mechanism_stem",
      "meaning": "tyrosine kinase inhibitor",
      "examples": ["imatinib", "erlotinib", "gefitinib", "osimertinib"]
    },
    "match_score": 0.90,
    "match_reasons": ["target_class_match", "mechanism_match", "chemical_class_match"]
  }
]
```

**`GET /api/v1/stems/list`** — 列出系统全部 514 条 INN 词干。

---

### 2.2 INN 名称生成

**`POST /api/v1/naming/generate`**

基于匹配到的词干，组合生成 INN 候选名。自动对接 9,378 条真实 INN 数据库进行去重。

请求示例：
```json
{
  "properties": {
    "target_class": "kinase",
    "mechanism": "inhibitor",
    "chemical_class": "small_molecule",
    "indication": "cancer"
  },
  "existing_names_to_avoid": [],
  "constraints": {
    "max_name_length": 20,
    "min_name_length": 4,
    "max_consecutive_consonants": 3,
    "max_consecutive_vowels": 2
  }
}
```

响应字段说明：

| 字段 | 说明 |
|------|------|
| `candidates` | 候选名列表（含音韵评分、监管标记） |
| `total_generated` | 原始生成总数 |
| `filtered_out` | 被过滤掉的数量 |

监管标记 (`regulatory_flags`) 含义：

| 标记 | 说明 |
|------|------|
| `exact_inn_conflict` | 与已有 INN 名称完全相同 |
| `trigram_match_with_existing` | 三字母组合高度重叠（>80%） |
| `contains_forbidden_prefix` | 包含禁用前缀 |
| `contains_forbidden_suffix` | 包含禁用后缀 |
| `too_many_consecutive_consonants` | 连续辅音过多 |
| `too_many_consecutive_vowels` | 连续元音过多 |

### 2.3 POCA 评分（核心功能）

POCA（Phonetic, Orthographic, Compositional Analysis）是 FDA 标准的三维度名称相似度评分系统。

**评分维度与权重：**

| 维度 | 权重 | 方法 |
|------|------|------|
| 语音 (Phonetic) | 40% | Soundex + Double Metaphone + 音节数 + 重音模式 |
| 字形 (Orthographic) | 35% | Levenshtein 编辑距离 + Bigram/Trigram 重叠 + 公共前后缀 |
| 组合 (Compositional) | 25% | 共享词干 + 词缀位置 + 首尾三字符匹配 |

**安全阈值：**
- `< 0.70` → PASS（通过）
- `0.70 ~ 0.85` → REVIEW（需人工审核）
- `> 0.85` → REJECT（驳回）

#### 2.3.1 标准对比评分

**`POST /api/v1/poca/score`**

候选名 vs 指定的参考名称列表。

请求示例：
```json
{
  "proposed_name": "aflisib",
  "reference_names": ["buparlisib", "idelalisib", "copanlisib"],
  "weights": {
    "phonetic_weight": 0.40,
    "orthographic_weight": 0.35,
    "compositional_weight": 0.25
  }
}
```

#### 2.3.2 智能对比评分

**`POST /api/v1/poca/smart-score`**

自动从 9,378 条 INN 数据库中选取最相关的同类药对比（如同一词干类别的药物），避免低效的全库对比。

```
POST /api/v1/poca/smart-score?proposed_name=aflisib&max_refs=10
```

#### 2.3.3 获取智能参考名

**`POST /api/v1/poca/smart-references`**

返回与候选名共享词干的真实 INN 名称列表，用于 POCA 对比。

```
POST /api/v1/poca/smart-references?proposed_name=aflisib&max_refs=5
```

#### 2.3.4 两名称直接对比

**`POST /api/v1/poca/compare`**

对比两个具体名称，返回完整的三维度评分明细。

```
POST /api/v1/poca/compare?proposed_name=aflisib&reference_name=buparlisib
```

### 2.4 中文核名

**`POST /api/v1/chinese/suggest`**

基于 INN 名称生成中文候选名。使用 pypinyin 映射音节到汉字，考虑偏旁相似度、笔画数、语义偏好。

请求示例：
```json
{
  "inn_name": "aflisib",
  "pharmacological_properties": {
    "target_class": "kinase",
    "mechanism": "inhibitor",
    "chemical_class": "small_molecule",
    "indication": "cancer"
  },
  "target_meaning": "抑制肿瘤",
  "max_candidates": 10
}
```

**`POST /api/v1/chinese/check`**

检查中文候选名与已批准名称的相似度。

请求示例：
```json
{
  "chinese_name": "阿氟利西",
  "approved_names_db": [
    {"chinese_name": "伊马替尼"},
    {"chinese_name": "吉非替尼"}
  ]
}
```

---

### 2.5 商品名筛选

**`POST /api/v1/brand/screen`**

四维度筛选商品名：

| 维度 | 权重 | 评估内容 |
|------|------|------|
| 与 INN 相似度 | 25% | 应与 INN 名保持差异 |
| 与已有品牌相似度 | 35% | 避免市场混淆 |
| 语义关联 | 20% | 正面/负面联想词检查 |
| 市场可注册性 | 20% | 长度、可读性、独特性 |

请求示例：
```json
{
  "proposed_brand_names": ["Zelafi", "Lisipro"],
  "inn_name": "aflisib"
}
```

### 2.6 命名项目管理（完整工作流）

项目管理 API 串联了从分子输入到最终决策的完整流程。

#### 工作流步骤

```
Draft → Stem Matching → Name Generation → POCA Screening → Chinese Naming → Brand Screening → Decision
```

#### 2.6.1 创建项目

**`POST /api/v1/projects/`**

```json
{
  "molecule_id": "MOL-2026-001",
  "common_name": "候选化合物A",
  "properties": {
    "target_class": "kinase",
    "mechanism": "inhibitor",
    "chemical_class": "small_molecule",
    "indication": "non-small cell lung cancer"
  }
}
```

#### 2.6.2 逐步推进工作流

按顺序调用以下端点，每一步会更新项目状态：

1. **`POST /api/v1/projects/{id}/workflow/stem-matching`** — 词干匹配
2. **`POST /api/v1/projects/{id}/workflow/generate-inn`** — 生成 INN 候选名（可选传入 `existing_names` 额外去重名单）
3. **`POST /api/v1/projects/{id}/workflow/poca-screen`** — POCA 智能筛选（自动使用同类药对比，也可传 `reference_names` 手动指定）
4. **`POST /api/v1/projects/{id}/workflow/chinese-naming`** — 生成中文名（可选传 `target_meaning` 指定语义方向）
5. **`POST /api/v1/projects/{id}/workflow/brand-screening`** — 商品名筛选（可选传 `proposed_brands`）
6. **`POST /api/v1/projects/{id}/workflow/decide`** — 最终决策

#### 2.6.3 最终决策

```json
{
  "decision": "approved",
  "notes": "POCA全部PASS，中文名合规，建议提交INN申请",
  "final_selection": {
    "inn_name": "aflisib",
    "chinese_name": "阿氟利西",
    "brand_name": "Zelafi"
  }
}
```

决策选项：`approved`（批准） / `rejected`（驳回） / `needs_revision`（需修改） / `escalated`（升级审查）

#### 2.6.4 其他项目管理端点

| 方法 | 端点 | 说明 |
|------|------|------|
| `GET` | `/api/v1/projects/` | 列出所有项目 |
| `GET` | `/api/v1/projects/{id}` | 查看项目详情（含全部中间结果） |

## 三、典型使用场景

### 场景1：快速验证一个新分子

```bash
# 1. 词干匹配
curl -X POST http://localhost:8000/api/v1/stems/match \
  -H "Content-Type: application/json" \
  -d '{"target_class":"kinase","mechanism":"inhibitor","chemical_class":"small_molecule","indication":"lung cancer"}'

# 2. 生成候选名
curl -X POST http://localhost:8000/api/v1/naming/generate \
  -H "Content-Type: application/json" \
  -d '{"properties":{"target_class":"kinase","mechanism":"inhibitor","chemical_class":"small_molecule","indication":"lung cancer"}}'

# 3. 对最佳候选名做 POCA 智能评分
curl -X POST "http://localhost:8000/api/v1/poca/smart-score?proposed_name=YOUR_CANDIDATE&max_refs=20"
```

### 场景2：完整项目工作流（单抗）

```bash
# 创建项目
curl -X POST http://localhost:8000/api/v1/projects/ \
  -H "Content-Type: application/json" \
  -d '{
    "molecule_id":"MAB-2026-042",
    "common_name":"抗PD-L1全人源单抗",
    "properties":{
      "target_class":"immune_checkpoint",
      "mechanism":"inhibitor",
      "chemical_class":"monoclonal_antibody",
      "indication":"solid tumors"
    }
  }'

# 假设 project_id = "xxx"
ID="xxx"

# 逐步推进
curl -X POST "http://localhost:8000/api/v1/projects/$ID/workflow/stem-matching"
curl -X POST "http://localhost:8000/api/v1/projects/$ID/workflow/generate-inn" \
  -H "Content-Type: application/json" -d '{"existing_names":[]}'
curl -X POST "http://localhost:8000/api/v1/projects/$ID/workflow/poca-screen"
curl -X POST "http://localhost:8000/api/v1/projects/$ID/workflow/chinese-naming?target_meaning=免疫"
curl -X POST "http://localhost:8000/api/v1/projects/$ID/workflow/brand-screening"

# 查看最终结果
curl -s "http://localhost:8000/api/v1/projects/$ID" | python3 -m json.tool
```

## 五、配置说明

系统配置通过 `drug_naming.config.EngineSettings` 管理，支持环境变量覆盖（前缀 `DN_`）：

| 参数 | 默认值 | 说明 |
|------|------|------|
| `poca_phonetic_weight` | 0.40 | POCA 语音维度权重 |
| `poca_orthographic_weight` | 0.35 | POCA 字形维度权重 |
| `poca_compositional_weight` | 0.25 | POCA 组合维度权重 |
| `poca_safety_threshold` | 0.70 | POCA REVIEW 阈值 |
| `poca_high_alert_threshold` | 0.85 | POCA REJECT 阈值 |
| `default_max_name_length` | 20 | 名称最大长度 |
| `default_min_name_length` | 4 | 名称最小长度 |
| `max_consecutive_consonants` | 3 | 最大连续辅音数 |
| `max_consecutive_vowels` | 2 | 最大连续元音数 |
